================================================================================
                 GWMouseBattery  ——  鼠标电量托盘显示
                                v1.0.0
================================================================================

【这是什么】

  在 Windows 右下角托盘区常驻显示鼠标电量的小工具。
  不用每次去开网页驱动，鼠标指针移到图标上就能看到电量。

  顺便还能在托盘右键菜单里直接切换（不用再开网页）：
      · SPDT 左右键开关
      · 灵敏度（DPI）
      · 回报率


【系统要求】

  · Windows 7 SP1 / 8 / 10 / 11（32 位或 64 位都可以）
  · .NET Framework 4.0 或以上 —— Windows 8 以上系统自带，不用装任何东西
  · 免安装、免注册、不写注册表。删掉文件夹就干净了，不留垃圾。


【怎么用】

  1. 把 GWMouseBattery.exe 放到任意文件夹（比如 D:\Tools\）。

  2. 双击它 —— 右下角托盘区就出现一个电池图标。
     ※ 直接双击 exe 就能用。「启动.bat」是个中文菜单，功能一样，备用。

  3. 鼠标指针移到图标上    ->  弹出电量 / 充电状态 / 电压
     左键单击图标          ->  打开详情窗口（大百分比 + 进度条）
     右键单击图标          ->  菜单

  4. 右键菜单里能干什么：
         显示详情 / 立即刷新
         SPDT（按键开关）
         灵敏度（DPI）
         回报率
         刷新间隔 / 图标样式
          开机自启
         诊断信息 / 退出

  ⚠️ Windows 11 会把新出现的图标收进「^」折叠区里。
     点一下 ^，把图标拖到任务栏上，以后就常驻了。
     本程序第一次成功读到电量时也会弹一次气泡提醒你这件事。


【开机自启】

  右键菜单 ->「开机自启」打勾即可（在当前用户的启动文件夹里放一个 .cmd）。
  想取消就把勾去掉，程序会把那个文件删掉。


【⚠️ 第一次运行会被 Windows / 杀软拦一下，这是正常的】

  这个 exe 没有购买数字签名证书（个人免费工具，证书要按年收费），因此：

    · Windows SmartScreen 可能弹「已保护你的电脑」
          -> 点「更多信息」，再点「仍要运行」

    · 杀软可能报「未知程序/可疑」
          -> 属于误报，加进白名单即可

  你可以自己核实它到底干了什么，不需要相信上面这句话：

    · 看源码：source\src\*.cs
        纯 C#，两个主要文件，中文注释齐全，能读懂每一行。

    · 自己编译：source\build.ps1
        用的是 Windows 自带的 C# 编译器（csc.exe），不需要装
        Visual Studio、不需要 .NET SDK、不需要联网下载任何东西。
        编译完会自动跑一遍 92 项逻辑自检。

  本程序只做两件事：读写鼠标这个 HID 设备；读写自己的设置文件。
  不联网、不读你的文档、不上传任何数据。


【能用在哪些鼠标上】

  · 主要针对 G-Wolves 系列（就是驱动网页是 mouse.pink / mouse.xyz 的那批
    白牌驱动鼠标）。

  · 程序会自动扫描设备并识别协议，不需要你选型号、也不用填 VID / PID。


  · 如果你的鼠标 Windows 自己就能显示电量（部分罗技 / 雷蛇等），
    那不需要这个工具。


【常见问题】

  Q: 提示读不到电量，或者图标一直灰着？
  A: 多半是鼠标省电休眠了。动一下鼠标、按一下键，几秒钟内会自动恢复。
     界面会保留 10 分钟内的最后一次有效值，并标注「（N 分钟前）」，
     所以不会因为一次读取失败就跳灰。

  Q: 改完灵敏度（DPI），感觉没变化？
  A: 先确认菜单标题上的数值确实变了（那是从鼠标读回来的真实值）。
     如果数值变了但手感没变，双击 tools\FindDPI.bat 做一次对比诊断。

  Q: 双击了两次，会不会出现两个图标？
  A: 不会。第二次启动只会把已经运行的详情窗口弹出来，
     永远只有一个图标。要关掉就在右键菜单里选「退出」。

  Q: 和网页驱动会不会打架？
  A: 不会，两边都能用。但网页驱动打开时可能会抢走鼠标的回复，
     导致本工具偶尔读不到 —— 过几秒会自己恢复。

  Q: 会不会把我鼠标设置改乱？
  A: 只有你主动点菜单里的 SPDT / 灵敏度 / 回报率 时才会写入，
     而且每次写完都会立刻回读校验。它不会偷偷改任何东西。
     真的改错了，用网页驱动或者本菜单改回来即可。


【出问题了怎么排查】

  右键菜单 ->「诊断信息」
      会列出所有 HID 接口。把内容复制下来，就能定位问题。
      命令行等价写法：  GWMouseBattery.exe --diag

  tools\FindDPI.bat   （查 DPI 存在哪）
      先读一遍鼠标的存储区，暂停，让你去网页驱动改一次 DPI，再读一遍，
      最后列出到底哪几个字节发生了变化。结果写在同目录的 dpidiff.txt。
      这是本程序当初用来锁定 DPI 真实存储地址的办法。

  tools\Sniff.bat     （抓包）
      监听 90 秒，把鼠标和电脑之间的全部通信写进 sniff.txt。
      只读，不会向鼠标发送任何命令。

  ⚠️ 跑上面这两个工具前，先在托盘右键菜单里「退出」，
     否则托盘程序会抢走鼠标的回复。


【卸载】

  1. 右键托盘图标 ->「退出」
  2. 如果开过开机自启，先在菜单里把勾去掉
  3. 删掉整个文件夹
  4. （可选）删掉 %APPDATA%\GWMouseBattery  （保存的只是界面偏好）
